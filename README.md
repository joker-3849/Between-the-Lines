# Between the Lines

Сайт книжного клуба: тёмная полка прочитанных книг, карточка каждой книги
с мнениями всех участниц, страница цитат, хроника встреч и лонгрид с итогами года.

Статический сайт без сборки: HTML, CSS и ES-модули. Все данные — два JSON-файла
в репозитории.

## Запуск

Браузер не отдаёт JSON по `file://`, поэтому нужен любой локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Для публикации подойдёт GitHub Pages: Settings → Pages → Deploy from a branch,
корень репозитория.

## Разделы

| Раздел | Что внутри |
|---|---|
| **Полка** | Шесть книг стоят лицом, остальные лежат стопкой справа. Поиск, фильтр по жанру и семь способов сортировки — в том числе «по разбросу мнений». Клик по обложке плавно разворачивает её в карточку книги (FLIP-перелёт). |
| **Книга** | Оценки сгруппированы **по критериям, а не по участницам**: на шкале 1–10 стоят точки с инициалами, рядом — среднее и метка «спорная» / «единогласно». Ниже — впечатления и выписанные строчки. |
| **Между строк** | Все строчки, которые участницы забрали с собой: свои формулировки с обсуждений и несколько цитат прямо из книг (помечены значком «из книги»). |
| **Хроника** | Встречи по датам, сгруппированные по годам. |
| **Итоги года** | Лонгрид с прокруткой: цифры года, книга года, строчка года, самая спорная книга, рекорды, жанры и средние оценки каждой участницы. Год переключается в шапке. |

## Данные

### `data/club.json`

Участницы, критерии оценки, шкала, ближайшая встреча.

```jsonc
{
  "cadenceDays": 14,             // шаг между встречами
  "nextMeeting": "2026-09-11",   // если дата в прошлом, она сама катится вперёд
  "currentlyReading": { "title": "…", "author": "…" },
  "members":  [{ "id": "katya", "name": "Катя", "initial": "К",
                 "color": "#d9a94c", "g": "f" }],
  "criteria": [{ "id": "overall", "label": "Общая оценка" }],
  "yearHighlights": { "2025": { "lineOfTheYear": { "bookId": "…", "memberId": "…" } } }
}
```

`g` — род («f» / «m»), нужен для подписей вроде «предложила Лиза» и «самый строгий».
Добавить участницу — добавить объект в `members`; все шкалы, фильтры и итоги
подхватят её автоматически.

### `data/books.json`

Одна книга — один объект. Мнение каждой участницы лежит в `reviews`:

```jsonc
{
  "id": "my",
  "title": "Мы", "author": "Евгений Замятин",
  "year": 1924, "pages": 224, "genre": "Фантастика",
  "edition": "Азбука, 2021",
  "tone": 5,                     // 0–5, цвет типографской обложки
  "discussed": "2026-07-09",     // дата встречи
  "proposedBy": "liza",
  "coverQuery": "Мы Замятин",    // по этому запросу ищется обложка
  "cover": "assets/covers/my.jpg",
  "reviews": {
    "tanya": {
      "scores": { "overall": 8, "plot": 8, "style": 9,
                  "characters": 8, "atmosphere": 10 },
      "text": "Впечатление в свободной форме.",
      "line": { "kind": "club", "text": "Строчка, которую забрала с собой." }
    }
  }
}
```

* `line.kind` — `"club"` для своей формулировки, `"book"` для цитаты из книги
  (она подписывается отдельно).
* `line` можно не заполнять — тогда просто `"line": null`.
* Всё, что дальше, считается само: средние, разброс, книга года, самый строгий
  критик, статистика жанров.

## Обложки

Сайт всегда рисует типографскую обложку, а поверх неё показывает картинку,
если та загрузилась. Порядок источников: сначала локальный файл из поля `cover`,
затем — необязательный массив `coverRemote` с внешними адресами.

Реальные обложки скачиваются одной командой (нужен Node 18+ и интернет):

```bash
node tools/fetch-covers.mjs               # всё, чего ещё нет
node tools/fetch-covers.mjs --force       # перекачать заново
node tools/fetch-covers.mjs --list my     # посмотреть издания на выбор
node tools/fetch-covers.mjs --pick my=2 --force   # взять третье издание
```

Скрипт ищет книгу на Open Library по `coverQuery`, проверяет, что пришла
настоящая картинка, и кладёт её в `assets/covers/<id>.jpg`. Файлы стоит
закоммитить — тогда сайт не зависит от чужого CDN. Если обложка не нашлась,
ничего не ломается: остаётся типографская.

## Оформление

* Дисплейный шрифт — **Cormorant**, текст и интерфейс — **Inter**.
* Иконки — инлайн-SVG в стиле **Tabler Icons** (24×24, обводка 1.5),
  лежат в `assets/js/icons.js`; заменить на файлы из tabler.io/icons можно,
  подставив другие `<path>` в тот же словарь.
* Тёмная палитра и все размеры — переменные в начале `assets/css/style.css`.
* Поверх страницы — слой зерна (`.grain`), это SVG-шум, а не картинка.
* Все анимации выключаются при `prefers-reduced-motion: reduce`.

```
    data.js       загрузка JSON, средние, разброс, даты, числительные
    ui.js         обложка, аватар участницы, шкала критерия
    shelf.js      полка, стопка, поиск, фильтр, сортировка
    book.js       карточка книги и FLIP-перелёт обложки
    pages.js      «Между строк», «Хроника», «Итоги года»
    icons.js      иконки
  covers/         реальные обложки (заполняется скриптом)
data/
  club.json
  books.json
tools/
  fetch-covers.mjs
```
