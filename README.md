# Between the Lines

Сайт книжного клуба: полка прочитанных книг, карточка каждой книги
с мнениями всех участниц, страница цитат, хроника встреч и лонгрид с итогами года.

Статический сайт без сборки: HTML, CSS и ES-модули. Все данные — два JSON-файла
в репозитории.

## Запуск

Браузер не отдаёт JSON по `file://`, поэтому нужен любой локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Для публикации подойдёт GitHub Pages: Settings → Pages → Deploy from a branch,
корень репозитория.

## Разделы

| Раздел | Что внутри |
|---|---|
| **Полка** | Семь книг стоят лицом, слегка развёрнутые корешком к зрителю, до пяти следующих лежат стопкой справа. Поиск, фильтр по жанру и семь способов сортировки — в том числе «по разбросу мнений». Клик по обложке плавно разворачивает её в карточку книги (FLIP-перелёт). |
| **Книга** | Оценки сгруппированы **по критериям, а не по участникам**: на шкале 1–10 стоят точки с инициалами, рядом — среднее и метка «спорная» / «единогласно». Ниже — «Перечитаешь?», впечатления и выписанные строчки. Кнопка **«Внести изменения»** превращает ту же страницу в форму — см. [«Правка карточки»](#правка-карточки). |
| **Между строк** | Все строчки, которые участницы забрали с собой: свои формулировки с обсуждений и несколько цитат прямо из книг (помечены значком «из книги»). |
| **Хроника** | Встречи по датам, сгруппированные по годам. |
| **Итоги года** | Лонгрид с прокруткой: цифры года, книга года, строчка года, самая спорная книга, рекорды, жанры и средние оценки каждой участницы. Год переключается в шапке. |
| **Добавить книгу** | Плитка с плюсом в конце полки открывает форму: название, автор, ISBN с живым предпросмотром обложки, рисунок обложки со сменой варианта и мнения участников по критериям. Подробности — в разделе [«Добавить книгу»](#добавить-книгу) ниже. |

## Данные

### `data/club.json`

Участницы, критерии оценки, шкала, ближайшая встреча.

```jsonc
{
  "cadenceDays": 14,             // шаг между встречами
  "nextMeeting": "2026-09-11",   // если дата в прошлом, она сама катится вперёд
  "currentlyReading": { "title": "…", "author": "…" },
  "members":  [{ "id": "katya", "name": "Катя", "initial": "К",
                 "color": "#d9a94c", "g": "f" }],
  "criteria": [                  // по ним и только по ним ставятся баллы
    { "id": "plot",       "label": "Сюжет и структура" },
    { "id": "characters", "label": "Персонажи" },
    { "id": "style",      "label": "Ясность и выразительность языка" },
    { "id": "themes",     "label": "Тематика и идеи" },
    { "id": "emotion",    "label": "Эмоциональное воздействие" }
  ],
  "yearHighlights": { "2025": { "lineOfTheYear": { "bookId": "…", "memberId": "…" } } }
}
```

`g` — род («f» / «m»), нужен для подписей вроде «предложила Лиза» и «самый строгий».
Добавить участника — добавить объект в `members`; все шкалы, фильтры и итоги
подхватят его автоматически. То же с критериями: список в `criteria` — источник
правды, и форма правки, и шкалы на карточке строятся прямо по нему.

**Среднего балла в данных нет.** Он всегда считается из выставленных критериев:
средний балл участника — среднее его оценок, средний балл книги — среднее по
участникам. Поэтому он не может разойтись с критериями после правки.

### `data/books.json`

Одна книга — один объект. Мнение каждой участницы лежит в `reviews`:

```jsonc
{
  "id": "my",
  "title": "Мы", "author": "Евгений Замятин",
  "year": 1924, "pages": 224, "genre": "Фантастика",
  "edition": "Азбука, 2021",
  "art": {                       // своя обложка, пока нет фотографии настоящей
    "bg": "#cfd6d8",             // фон
    "fg": "#1a2226",             // текст
    "acc": "#c02a20",            // цвет рисунка
    "motif": "grid"              // сам рисунок, см. ниже
  },
  "discussed": "2026-07-09",     // дата встречи
  "proposedBy": "liza",
  "coverQuery": "Мы Замятин",    // по этому запросу ищется обложка
  "cover": "assets/covers/my.jpg",
  "isbn": "9780140185855",       // ISBN издания — по нему ищется фото на Open Library
  "reviews": {
    "tanya": {
      "scores": {                // ключи — id критериев из club.json
        "plot": 8, "characters": 8, "style": 9,
        "themes": 8, "emotion": 10
      },
      "reread": true,            // «Перечитаешь?»: true / false / null
      "text": "Впечатление в свободной форме.",
      "line": { "kind": "club", "text": "Строчка, которую забрала с собой." }
    }
  }
}
```

* `scores` может быть заполнен частично — среднее считается по тому, что есть.
* `reread` — `true` (да), `false` (нет) или `null`, если человек не ответил;
  в блоке «Перечитаешь?» показываются только ответившие.
* `line.kind` — `"club"` для своей формулировки, `"book"` для цитаты из книги
  (она подписывается отдельно).
* `line` можно не заполнять — тогда просто `"line": null`.
* Всё, что дальше, считается само: средний балл, разброс, книга года, самый
  строгий критик, статистика жанров.

## Обложки

Сайт всегда рисует свою обложку из поля `art`, а поверх неё показывает
фотографию настоящей, если та загрузилась. Порядок источников: сначала
локальный файл из поля `cover`, затем — необязательный массив `coverRemote`
с внешними адресами.

### Переключатель на полке

В панели над полкой есть переключатель **свои / настоящие**:

* **свои** — всегда показываются нарисованные обложки. Картинки не
  запрашиваются вообще, полка выглядит как единая серия.
* **настоящие** — сайт пробует показать фотографию настоящего издания, а
  нарисованная остаётся под ней запасным вариантом. Порядок попыток:
  локальный файл из `cover` → адрес, собранный по `isbn` → адреса из
  `coverRemote`. Если ни одна картинка не загрузилась, под панелью появляется
  подсказка.

Выбор запоминается в браузере читателя (`localStorage`), в данные клуба
не попадает. Значение по умолчанию задаётся в `assets/js/settings.js`.

Важная оговорка про предпросмотр в артефакте Claude: там внешние картинки,
включая `covers.openlibrary.org`, не грузятся вовсе (это ограничение
песочницы, а не сайта) — режим «настоящие» там всегда откатывается на
нарисованные обложки. На GitHub Pages, локальном сервере или в любом обычном
браузере фотографии подгружаются как обычно.

### ISBN и обложка с Open Library

Поле `isbn` — это ISBN конкретного издания (13 или 10 цифр, без дефисов).
Из него собирается адрес `covers.openlibrary.org/b/isbn/<isbn>-L.jpg`.
`isbn: null` — кода нет, показывается нарисованная обложка.

ISBN двенадцати книг в текущих данных подобраны по памяти (сеть к
Open Library была недоступна в момент, когда их вписывали) — с высокой,
но не стопроцентной уверенностью, что это те самые издания. Стоит один раз
проверить и поправить то, что не подтвердится:

```bash
node tools/fetch-covers.mjs --verify
```

Команда проходит по всем ISBN в `books.json` и для каждого сообщает, отдаёт
ли Open Library настоящую картинку. Если что-то не подтвердилось — посмотрите
варианты и впишите верный ISBN:

```bash
node tools/fetch-covers.mjs --list my                          # список изданий с их ISBN
node tools/fetch-covers.mjs --isbns --pick my=2 --force         # вписать ISBN конкретного варианта
```

Так же можно найти ISBN для новой книги, если он неизвестен, — по названию
и автору из `coverQuery`:

```bash
node tools/fetch-covers.mjs --isbns          # найти и вписать ISBN всем книгам без него
node tools/fetch-covers.mjs --isbns --force  # переподобрать даже тем, у кого уже есть
```

Скрипт каждый раз сам проверяет, что по ISBN действительно отдаётся картинка,
а не просто существует запись — ничего наугад не вписывает.

### Рисунок на обложке

У каждой книги своя палитра и мотив — простая геометрия, отсылающая
к содержанию. Мотивы живут в `assets/js/covers.js`, добавить новый — дописать
функцию в объект `MOTIFS` (сетка 200×300, цвет берётся из `var(--acc)`).

| `motif` | что рисует | где сейчас |
|---|---|---|
| `moon` | полная луна и рамка вокруг | Мастер и Маргарита |
| `rain` | дождь между стволами | Норвежский лес |
| `deco` | веер ар-деко из угла | Убийство Роджера Экройда |
| `zone` | свечение над обочиной | Пикник на обочине |
| `frame` | картина в раме | Щегол |
| `veil` | молочная белизна | Слепота |
| `orbit` | орбиты вокруг точки | Краткая история времени |
| `regency` | двойная рамка с ромбом | Гордость и предубеждение |
| `sun` | зной, лучи из угла | Сто лет одиночества |
| `water` | круги по воде | Все, чего я не сказала |
| `planet` | планета с кольцом и звёзды | Автостопом по галактике |
| `grid` | стеклянная сетка | Мы |

`"motif": null` — обложка останется просто цветной, без рисунка.

Файлы обложек тоже можно скачать в репозиторий, а не грузить их с Open Library
каждый раз (надёжнее — сайт перестаёт зависеть от чужого CDN):

```bash
node tools/fetch-covers.mjs               # скачать в assets/covers/ по уже вписанным ISBN
node tools/fetch-covers.mjs --force       # перекачать заново
```

Если для книги ещё нет ISBN, эта же команда на всякий случай поищет обложку
и по `coverQuery`. Ничего не ломается, если обложка не нашлась — остаётся
типографская.

Все режимы разом:

```bash
node tools/fetch-covers.mjs --verify                             # проверить вписанные ISBN
node tools/fetch-covers.mjs --isbns                               # найти и вписать ISBN
node tools/fetch-covers.mjs --list my                             # посмотреть варианты изданий
node tools/fetch-covers.mjs --isbns --pick my=2 --force           # взять конкретный вариант
node tools/fetch-covers.mjs                                       # скачать файлы в assets/covers/
```

## Добавить книгу

Плитка с плюсом в конце полки открывает форму: название и автор обязательны,
остальное — по желанию, включая ISBN (с живым предпросмотром обложки прямо
в форме) и мнения участниц, которые разворачиваются по одной.

Сайт статический и читает полку из файла в репозитории, поэтому форма не
пишет в `data/books.json` сама:

1. Книга сразу появляется на полке и открывается её страница — так виднее,
   получилось ли то, что нужно. Это черновик, который живёт только в памяти
   текущей вкладки: обновите страницу — и он пропадёт.
2. На странице черновика есть кнопка «Показать JSON для вставки» — она
   собирает объект книги в точности в формате `books.json`.
3. Скопируйте его (кнопка справляется сама, а если браузер не даёт доступ
   к буферу обмена — текст уже выделен, остаётся Ctrl/Cmd+C) и вставьте
   отдельным элементом в массив в `data/books.json`.
4. Если вписали ISBN, стоит один раз проверить его —
   `node tools/fetch-covers.mjs --verify`.
5. Закоммитьте.

Мнение участника попадает в экспорт, только если для него заполнено хоть
что-то — пустые карточки в `reviews` не создаются.

## Правка карточки

Кнопка **«Внести изменения»** на странице книги превращает эту же страницу
в форму: слева обложка и поля книги (название, автор, год, объём, жанр,
издание, ISBN, дата обсуждения, кто предложил), справа — карточка каждого
участника.

Баллы ставятся кликом: критерий, под ним ряд кружков 1…10. Повторный клик по
выбранной цифре снимает оценку. Средний балл участника пересчитывается прямо
в форме, пока вы кликаете, — вводить его негде и незачем. Ниже — «Перечитаешь?»
(да / нет, тоже переключаются повторным нажатием), впечатление и строчка,
забранная с собой.

Тот же элемент используется и в форме добавления книги — он живёт в
`assets/js/ui.js` (`scorePickerHTML`, `wirePickers`, `readPicked`), так что
оба места ведут себя одинаково.

Сохранение работает как и у новой книги: сайт статический и в файлы не пишет,
поэтому «Сохранить» правит книгу в памяти вкладки и вешает на карточку
плашку «изменено» с кнопкой «Показать JSON для вставки». Скопируйте объект
и замените им соответствующий элемент массива в `data/books.json`.
Уход со страницы с несохранёнными правками спрашивает подтверждение;
«Отменить» возвращает карточку в режим чтения, ничего не записав.

## Оформление

* Дисплейный шрифт — **Instrument Serif** (только начертание 400 — вес
  не варьируется, это часть его характера), текст и интерфейс — **Inter**.
* Тёплая светлая палитра: кремовая бумага, глубокий бордовый акцент вместо
  прежнего золота. Все цвета и размеры — переменные в начале
  `assets/css/style.css` (`--void`, `--ink`, `--gold` и т. д. — имена
  остались прежними, поменялись только значения). Цвета обложек живут
  в данных, а не в CSS: `--bg`, `--fg` и `--acc` подставляются из поля
  `art` каждой книги — сами обложки остаются тёмными и разноцветными,
  как настоящие книги на светлой полке.
* Формы везде мягкие: скруглённые карточки, поля и кнопки вместо прежних
  прямых углов.
* Иконки — инлайн-SVG в стиле **Tabler Icons** (24×24, обводка 1.5),
  лежат в `assets/js/icons.js`; заменить на файлы из tabler.io/icons можно,
  подставив другие `<path>` в тот же словарь.
* Поверх страницы — слой зерна (`.grain`), это SVG-шум, а не картинка.
* Все анимации выключаются при `prefers-reduced-motion: reduce`.

## Полка: нахлёст вместо скролла

На полке всегда ровно семь книг лицом (`FACE_OUT` в `assets/js/shelf.js`)
и до пяти следующих — стопкой (`PILE_MAX`); всё, что не поместилось сверх
этого, просто не показывается — ни на полке, ни в стопке. Ряд обложек
при этом никогда не скроллится по горизонтали: вместо этого он подгоняется
под фактическую ширину экрана нахлёстом — небольшим, если места хватает,
и заметно плотнее (книги «внахлёст», почти корешок к обложке), если нет.
Это осознанный выбор в пользу простоты и предсказуемой раскладки, а не
попытка бесконечно вместить растущую библиотеку — если книг в клубе
станет больше 12, часть просто не попадёт на полку; найти их всё ещё
можно через поиск и фильтр по жанру (они действуют на всю полку, а не
только на то, что показано).

Ряд, плитка «добавить книгу» и стопка всегда стоят в одну строку и никогда
не переносятся. При сужении окна полка сжимается плавно, без ступенек:
`--cover-w` — это `clamp(96px, 13.6vw, 196px)`, а высота и толщина корешка
считаются от неё, так что книги не перескакивают в другой размер на каждом
брейкпоинте, а просто встают плотнее — остальное добирает нахлёст, который
`fitFrontRow()` пересчитывает по фактической ширине ряда. Стопка ужимается
по ширине вместе с полкой, длинные названия в ней уходят в многоточие.
Проверено на ширинах от 360 до 1600 px: семь книг лицом, пять в стопке,
горизонтальной прокрутки страницы нет.

Одна тонкость для будущих правок: ширину обложки `fitFrontRow()` измеряет
через `offsetWidth` самой книги, а не читает `--cover-w`. Значение
пользовательской переменной приходит из `getComputedStyle` неразрешённым —
`clamp(96px, 13.6vw, 196px)` так и останется строкой.

### Панель над полкой

Поиск, чипы жанров, сортировка и переключатель обложек всегда в одну строку.
Прокручиваться позволено только полосе жанров: видно несколько чипов, край
последнего уходит под мягкую маску справа, остальные докручиваются вбок.
На узких экранах у сортировки и переключателя пропадают ведущие иконки,
подпись «настоящие» сокращается до «фото», а поиск сворачивается в иконку
и разворачивается обратно по фокусу.

### Наклон и наведение

В покое книга развёрнута корешком к зрителю на `--tilt` (30° по умолчанию),
при наведении разворачивается лицом (`rotateY(0)`) и приподнимается; соседи
слева и справа приподнимаются следом, но меньше и не выравниваются — волна
затухает через один слот.

Два неочевидных места:

* `perspective` стоит на `.slot`, а не на ряде. Перспектива действует только
  на прямых детей, а между рядом и `.book3d` стоит слот — на ряде наклон
  выродился бы в простое сжатие обложки по горизонтали вместо разворота.
* Сам слот при этом остаётся плоским (никакого `transform-style: preserve-3d`),
  а z-index висит на `.slot`, а не на `.book3d`. Иначе соседние книги делят
  одну 3D-сцену, браузер сортирует их по фактической геометрической глубине
  вместо z-index, и наведённая книга не может подняться поверх соседей.

## Структура

```
index.html
assets/
  css/style.css
  js/
    app.js        точка входа, переключение разделов
    data.js       загрузка JSON, средний балл, разброс, даты, числительные
    ui.js         обложка, аватар участника, шкала критерия, кружки 1…10
```

## Публикация

Ветка `claude/between-the-lines-website-frqpmo` — основная в этом репозитории,
и сайт лежит в корне, поэтому GitHub Pages подключается без сборки:
Settings → Pages → Source: **Deploy from a branch** → эта ветка, папка **/ (root)**.
Через минуту сайт открывается по адресу
`https://joker-3849.github.io/Between-the-Lines/`, а каждый `git push`
обновляет его сам.
